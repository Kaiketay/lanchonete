# Lanchonete

Este projeto implementa uma lanchonete fictícia com cardápio e carrinho de compras.

## Demonstração
Abra o arquivo [teste.html](teste.html) em seu navegador para testar a aplicação localmente.

## Instruções de uso

1. Clone este repositório.
2. Certifique-se de ter [Node.js](https://nodejs.org/) e npm instalados.
3. Instale as dependências com:
   ```bash
   npm install
   ```
4. Abra o arquivo `teste.html` no navegador ou sirva o diretório com a ferramenta de sua preferência.

## Testes

Para executar os testes unitários, utilize:

```bash
npm test
```

Para os testes de ponta a ponta, execute:

```bash
npm run e2e
```

Os testes dependem das bibliotecas **Jest** (unitários) e **Cypress** (e2e). Certifique-se de que essas dependências estejam instaladas antes de rodar os comandos acima.
